# 10.38 Multiple Domes? (CBM)

[↑ Advanced dominions III discussions](/kb-dominions/11-advanced-dominions-iii-discussions/README.md)

```text
Q: If I have multiple domes (same types or mixed) protecting a province, do enemy spells need to pass through ALL of them? Or, does the spell pick a random one and fail/pass based upon that one dome only?


A: 
- Only needs to pass through one, but can only pop one
- Stacking domes is still a good idea because of someone tries to bombard you with many remote spells, once one breaks the air dome, you have more backups to prevent the rest
- I think when you have A and N domes up, the A domes stop spells until they all break. The spell that breaks the A dome gets to hit the prov. Once all the A domes break, then the N domes have a 40% chance (just one, doesn't matter how many N domes you stacked) to stop a spell. If an N dome stops an F spell, it can break.

If you have F or W domes (and probably B), these operate in parallel and blast the caster whose spell may or may not have happened to have been stopped by (or bypassed) a A/N dome. 

I'm not sure how S domes stack with A and N.

The only way I can figure out how to visualize stacked A/N domes is that only one A/N dome can physically manifest at a time. The stacked domes are just waiting to materialize once the currently manifested dome pops.
- Dome stacking was changed somewhat in one patch, because it used to be that all domes stacked with all other domes, making it possible to make completely invulnerable provinces. That was not the intent of domes, so the current mechanics replaced the old.
```
