# sed

* [Sed - An Introduction (Bruce Barnett, 2005)](/sed/sed-tut.md) - An older copy (last updated 2005-07-04) of Bruce Barnett's sed tutorial; overlaps with the 2007 copy of the same tutorial.
* [Sed - An Introduction and Tutorial (Bruce Barnett, 2007)](/sed/sed-tutorial.md) - Bruce Barnett's widely-read sed tutorial: substitution, addresses, regular expressions, the hold space, branching and many worked examples.
* [Useful One-Line Scripts for Sed (Eric Pement)](/sed/sed-one-liners.md) - Eric Pement's classic collection of sed one-liners (version 5.5, 2005): spacing, numbering, text conversion and substitution, selective printing and deletion.
