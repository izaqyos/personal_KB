# Capacity

Read dates, working week, holidays, part-time fractions, leave, and allocation from authorized sources. Count actual available person-days, subtract overlapping leave once, and show arithmetic. Keep person-days separate from story points unless an explicit empirical conversion exists. Detect critical coverage overlaps and discrepancies between stated absence and filed leave. Missing evidence means unverified. Return inputs, assumptions, per-person totals, team total, conflicts, and options.

Locate optional sources through private configuration described in [portable setup](../../README.md). Use available authenticated CLI tools/connectors or user-supplied material; report missing dependencies and stop dependent work rather than inventing evidence. Preserve user scope. External posting, deployments, destructive actions, and account changes require the user's authorization. Never store credentials, real rosters, or private runtime data in this package.
