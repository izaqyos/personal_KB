# Execution Report

Read recent evidence and the previous report; reconcile changes in totals and state. Lead with completed outcomes. For active work, state actual owner, state, material blocker, and supported due date. Close loops with outcome and evidence. Flag stale sources. Avoid turning recommendations into commitments or implicitly assigning the user work. Use a short audience-appropriate plain-text draft, keeping personal sensitive material out of shared reports.

Locate optional sources through private configuration described in [portable setup](../../README.md). Use available authenticated CLI tools/connectors or user-supplied material; report missing dependencies and stop dependent work rather than inventing evidence. Preserve user scope. External posting, deployments, destructive actions, and account changes require the user's authorization. Never store credentials, real rosters, or private runtime data in this package.
