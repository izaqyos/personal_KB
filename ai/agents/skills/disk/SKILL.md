# Disk

Measure real volume usage and largest directories first. Distinguish physical space from logical cloud-file size and storage-category labels. Classify each target as regenerable cache, reproducible with effort, or unique. Untracked model progress reviews may be irreplaceable. Prefer tool-native prune commands; respect locks and in-use checks. Sync-folder deletion destroys remote content, so use provider eviction for local space. Show destructive targets, execute authorized steps one at a time, and remeasure. Check backup coverage before unique data; report denials without bypassing them.

Locate optional sources through private configuration described in [portable setup](../../README.md). Use available authenticated CLI tools/connectors or user-supplied material; report missing dependencies and stop dependent work rather than inventing evidence. Preserve user scope. External posting, deployments, destructive actions, and account changes require the user's authorization. Never store credentials, real rosters, or private runtime data in this package.
