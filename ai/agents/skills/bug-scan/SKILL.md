# Bug Scan

Load team/domain filters from private configuration. Query recent issues and older unresolved items; paginate the full requested scope. Inspect owner, status, recent comments, duplicate links, impact, and last update before labeling an issue unattended. Classify unassigned, untriaged, aging, blocked, or already handled. Before claiming a tenant-specific cause, check the same error across entities and time. Return priority, link, impact evidence, owner, last activity, and proposed next action. Routing recommendations are not confirmed ownership.

Locate optional sources through private configuration described in [portable setup](../../README.md). Use available authenticated CLI tools/connectors or user-supplied material; report missing dependencies and stop dependent work rather than inventing evidence. Preserve user scope. External posting, deployments, destructive actions, and account changes require the user's authorization. Never store credentials, real rosters, or private runtime data in this package.
