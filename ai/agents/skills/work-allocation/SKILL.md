# Work Allocation

Read actual work, availability, priorities, dependencies, and ownership evidence. Confirm capacity before filling perceived idle time. Rank a small set of independently actionable items by fit, effort uncertainty, blockers, and impact on committed work. Check critical coverage gaps and single-owner dependencies. Blocked work is not productive capacity and unestimated work is not automatically quick. Recommendations do not authorize reassignment.

Locate optional sources through private configuration described in [portable setup](../../README.md). Use available authenticated CLI tools/connectors or user-supplied material; report missing dependencies and stop dependent work rather than inventing evidence. Preserve user scope. External posting, deployments, destructive actions, and account changes require the user's authorization. Never store credentials, real rosters, or private runtime data in this package.
