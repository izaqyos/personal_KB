# Issue Triage

Load project, workflow, and ownership settings. Inspect reproduction, comments, linked issues, logs, and relevant changes. Classify impact, severity, confidence, boundary, and current handling. Routing follows evidence from ownership and code, with uncertainty explicit. Decompose into independently verifiable slices, acceptance criteria, dependencies, risks, and estimates with assumptions; count parent/child scope once. Validate query fields and quote inputs safely. Return full source links. Suggested transitions and assignments remain proposals until authorized.

Locate optional sources through private configuration described in [portable setup](../../README.md). Use available authenticated CLI tools/connectors or user-supplied material; report missing dependencies and stop dependent work rather than inventing evidence. Preserve user scope. External posting, deployments, destructive actions, and account changes require the user's authorization. Never store credentials, real rosters, or private runtime data in this package.
