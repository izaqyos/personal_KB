# Planning

Read live scope, priorities, estimates, owners, dates, capacity, and dependencies. Separate committed scope, candidates, and unestimated work; avoid double-counting parent and children. Compare demand and supply in consistent units with assumptions. Recommend assignments using availability, expertise, continuity, and dependency order. Surface bottlenecks, unowned epics, and dependencies with owner/ETA/impact. For new initiatives give goal, in/out scope, milestones, owners, risks, and first step. Return options and decisions when demand exceeds capacity.

Locate optional sources through private configuration described in [portable setup](../../README.md). Use available authenticated CLI tools/connectors or user-supplied material; report missing dependencies and stop dependent work rather than inventing evidence. Preserve user scope. External posting, deployments, destructive actions, and account changes require the user's authorization. Never store credentials, real rosters, or private runtime data in this package.
