# Tools Inventory

Search configured code/script roots before writing a duplicate. Confirm a candidate exists and inspect CLI help or docs. Catalog path, purpose, inputs, outputs, runtime/venv, version, and callers where useful. Distinguish entry points from modules. Give the exact safe invocation, not a stale indexed path. On refresh report new, missing, and moved entries and propose index changes. Keep credentials out of examples; use parameterized subprocess arguments in new code.

Locate optional sources through private configuration described in [portable setup](../../README.md). Use available authenticated CLI tools/connectors or user-supplied material; report missing dependencies and stop dependent work rather than inventing evidence. Preserve user scope. External posting, deployments, destructive actions, and account changes require the user's authorization. Never store credentials, real rosters, or private runtime data in this package.
