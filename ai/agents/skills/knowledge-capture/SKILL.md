# Knowledge Capture

Read source and existing notes before writing; verify that destination classification permits the material. Prefer enriching a canonical note over duplication. Preserve technical meaning, headings, tables, and links while removing navigation chrome. Use kebab-case and record source, capture date, and version when available. Add a linked contents list for substantial notes. Capture mechanism, assumptions, tradeoffs, and failure modes. Replacing a company label is not adequate generalization. Update indexes and capture log, verify links, and re-read. Report missing sources rather than fabricate them.

Locate optional sources through private configuration described in [portable setup](../../README.md). Use available authenticated CLI tools/connectors or user-supplied material; report missing dependencies and stop dependent work rather than inventing evidence. Preserve user scope. External posting, deployments, destructive actions, and account changes require the user's authorization. Never store credentials, real rosters, or private runtime data in this package.
