# Self Assessment

Read the requested period, role expectations, completed work, outcomes, feedback, and prior goals. For each claim record dated evidence, contribution, outcome, and attribution limits. Separate team results from individually attributable work; verify metrics and denominators. Organize around supported outcomes and lessons. Keep personal records and colleague feedback out of public knowledge repositories; uncertain claims remain candidates for verification.

Locate optional sources through private configuration described in [portable setup](../../README.md). Use available authenticated CLI tools/connectors or user-supplied material; report missing dependencies and stop dependent work rather than inventing evidence. Preserve user scope. External posting, deployments, destructive actions, and account changes require the user's authorization. Never store credentials, real rosters, or private runtime data in this package.
