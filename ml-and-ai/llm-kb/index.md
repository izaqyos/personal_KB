* [Open Knowledge Format (OKF)](/ml-and-ai/llm-kb/open-knowledge-format-okf.md) - OKF is a vendor-neutral spec for representing curated knowledge as a directory of markdown files with YAML frontmatter, so AI agents (and humans) can read, write, and exchange it without any SDK, runtime, or proprietary platform. Google Cloud announced it on 2026-06-12; v0.1 at launch ("a starting point, not a finished standard"); v0.2 since 2026-07-24 adds provenance, trust, lifecycle and attested computations.
* [Ornith-1.0 — Self-Scaffolding Open Models for Agentic Coding](/ml-and-ai/llm-kb/ornith-1.0-agentic-coding-model.md) - Ornith-1.0 is an open-source (MIT) family of LLMs from DeepReinforce AI, released 2026-06-25, purpose-built for agentic coding (multi-file refactors, test-driven patches, tool-using autonomous loops). Its headline idea is self-scaffolding RL: the model learns *its own* harness/scaffold (task plan, tool calls, error recovery) jointly with the solution policy during reinforcement learning, instead of relying on a hand-designed agent harness.
