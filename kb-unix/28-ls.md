[↑ unix-kb](/kb-unix/README.md)

## 28.1 ls sort by size

```text
ls -- sort by size

ls -S                # GNU/FSF version. Unsupported in a few unix flavors.

ls -s | sort         # useful even if imperfect
ls -s | sort -n 

ls -al | sort -n +4
```
